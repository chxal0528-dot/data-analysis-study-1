# Football Data Analysis Project

基于 Python 的足球数据分析项目，完成数据清洗、统计分析与可视化展示。

## Project Introduction

随着数据分析技术在体育、商业和工程领域的广泛应用，数据驱动决策逐渐成为重要方法。

本项目使用 Python 数据分析工具，对足球相关数据进行处理，包括：

- 数据清洗与整理
- 数据统计分析
- 数据可视化
- 分析结果展示

通过多个维度对不同国家足球发展情况进行探索。

# Analysis Contents

## 1. Player Age Structure Analysis

通过统计不同国家队球员年龄数据，分析：

- 平均年龄
- 年龄分布
- 不同球队年龄结构差异

使用：

- 数据整理
- 分组统计
- 可视化分析


## 2. National Team Comparison

对不同国家足球队进行多维度比较：

分析指标包括：

- 球员年龄
- 球队投入
- 成绩表现

通过雷达图等方式展示不同国家之间的差异。


## 3. League Data Analysis

对不同国家足球联赛数据进行分析：

主要包括：

- 联赛投入情况
- 球员支出情况
- 国家足球发展水平比较


## 4. Data Visualization

项目使用多种图表展示分析结果：

- 柱状图
- 雷达图
- 散点图
- 气泡图

帮助直观理解数据规律。

# Results

通过数据分析得到：

- 不同国家足球发展模式存在明显差异
- 球员年龄结构与球队发展阶段具有一定关联
- 联赛投入水平与足球竞争力之间存在一定联系

同时掌握了从原始数据到分析结果的完整流程。
